# Making of

The making of NeShop: the commands used to create the projects.

## Backend Shop Server API

```Sh
cd ~/Dev/neshop-aca/src/

mkdir ShopServer

cd ~/Dev/neshop-aca/src/ShopServer

dotnet new sln -n ShopServer
dotnet sln ./ShopServer.sln migrate

rm ./ShopServer.sln

dotnet new webapi --use-controllers -n Host --framework net10.0
dotnet sln add ./Host/Host.csproj

dotnet new classlib -n Contracts --framework net10.0
dotnet sln add ./Contracts/Contracts.csproj

dotnet new classlib -n Core --framework net10.0
dotnet sln add ./Core/Core.csproj

dotnet new classlib -n Database --framework net10.0
dotnet sln add ./Database/Database.csproj

# add Swagger UI package
dotnet add Host package Swashbuckle.AspNetCore.SwaggerUI --version 10.1.0

# add EF core and migrations
dotnet add Host package Microsoft.EntityFrameworkCore.Design --version 10.0.0 # need to add to startup project

dotnet add Host package Npgsql.DependencyInjection
dotnet add Host package Azure.Identity

dotnet add Database package Microsoft.EntityFrameworkCore --version 10.0.0
dotnet add Database package Microsoft.EntityFrameworkCore.Design --version 10.0.0

# add Postgres
dotnet add Database package Npgsql.EntityFrameworkCore.PostgreSQL --version 10.0.0

# add references between projects in backend

dotnet add reference Contracts               --project Database
dotnet add reference Contracts Database      --project Core
dotnet add reference Contracts Database Core --project Host
```

### Trust HTTPS Dev Cert

```Sh
cd ~/Dev/neshop-aca/src/ShopServer/Host/

dotnet dev-certs https --trust
```

## Frontend Shop Blazor

```Sh
cd ~/Dev/neshop-aca/src/

mkdir ShopWebl

cd ~/Dev/neshop-aca/src/ShopWebl

dotnet new sln -n ShopWebl
dotnet sln ./ShopWebl.sln migrate

rm ./ShopWebl.sln

dotnet new blazor -n WebFrontend --framework net10.0
dotnet sln add ./WebFrontend/WebFrontend.csproj

# create the client as a library to call the ShopServer API's
dotnet new classlib -n ShopClient --framework net10.0
dotnet sln add ShopClient

# need for autogenerated OpenApi client in frontend project
dotnet add ShopClient package Newtonsoft.Json --version 13.0.4

dotnet new classlib -n WebContracts --framework net10.0
dotnet sln add WebContracts

dotnet new classlib -n WebCore --framework net10.0
dotnet sln add WebCore

# add references between projects in frontend

dotnet add reference ShopClient                      --project WebContracts
dotnet add reference WebContracts ShopClient         --project WebCore
dotnet add reference WebContracts ShopClient WebCore --project WebFrontend
```
